# Veyin

A simple weight and body-measurement tracker. Works offline as an app on your phone. Everything stays on your device.

**Use it:** https://wictorstenseke.github.io/health-track/ (on iPhone: Share → Add to Home Screen)

## Develop

```sh
npm install
npm run dev     # start locally
npm test        # run tests
npm run build   # production build
```

Pushing to `main` deploys to GitHub Pages.
